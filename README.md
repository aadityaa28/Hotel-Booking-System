# Hotel Booking System

A beginner-friendly console-based Hotel Booking System developed in C.

## Features

- Select different room types
- Calculate room charges based on the number of days
- Book multiple rooms
- Add optional breakfast
- Apply discounts based on the length of stay
- Display discount details
- Generate a detailed final bill
- Confirm the booking

## Room Types

- Standard Room - Rs. 2000/day
- Deluxe Room - Rs. 3500/day
- Suite - Rs. 5000/day

## Discount Rules

- Less than 4 days - 0% discount
- 4 to 7 days - 10% discount
- More than 7 days - 15% discount

## Concepts Used

- If-else
- Functions
- Variables and data types
- User input and output
- Arithmetic operations
- Basic C programming
